# Catálogo de Serviços — Laboratório Unidade V

Projeto didático para compreender uma base existente, investigar um sintoma, formular hipóteses, corrigir em pequeno escopo, criar teste de regressão e revisar o diff.

## Sintoma informado pela área

Ao consultar serviços da categoria `Ambiental`, um serviço inativo também aparece no resultado.

## Execução dos testes

```powershell
python -m unittest discover -s tests -v
```

## Observação

O projeto é propositalmente pequeno. A atividade não é encontrar o erro o mais rápido possível, mas demonstrar um processo verificável de engenharia.
