# Regras de negócio

RN01 — Serviços inativos permanecem cadastrados para preservar histórico.

RN02 — `listar_ativos()` retorna somente serviços ativos.

RN03 — Consultas operacionais por categoria retornam somente serviços ativos.

RN04 — Nesta versão, a categoria é comparada de forma exata.

RN05 — Não se deve remover um serviço inativo do catálogo apenas para fazê-lo desaparecer das consultas.
